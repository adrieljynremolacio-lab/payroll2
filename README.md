# Payroll Manager v3

## Included
- Employee enrollment
- CSV upload: Employee Name, Position, Pay Rate
- Position dropdown:
  Foreman, Welder, Erector, Helper, Safety Officer, Engineer, Secretary
- Add future positions
- Manual hourly pay rate
- Payroll grid matching the requested layout
- First P = Position; second P = paid/store-hours field
- Paid-hour columns F, S, S, M, T, W, TH
- Thours formula
- Salary = Thours x Pay Rate
- ADD
- Rose Canteen
- Rose Canteen To Thur
- Over
- PP2 NO.25
- April
- Uniform
- Liza Canteen
- Net pay formula
- Excel export with actual Excel formulas
- Google Sheets Apps Script sync
- Browser local persistence

## Netlify
This is Vite + React. Netlify's current Vite guidance uses `npm run build` and `dist` as the publish directory.
